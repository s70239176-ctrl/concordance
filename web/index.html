An oracle for situations people see differently

Every oracle collapses disagreement into one answer. Concordance keeps it.

Several parties see the same situation differently. Independent validators on different models read all of it, and the network agrees on a record of what is settled, what is contested, how contested, and why. Contracts then act on that record, with money moving in proportion to how settled the facts really are.

09Why this only works on GenLayer

Consensus on meaning

LLMs never return the same prose twice. Concordance makes them agree on a small, snapped, structured object through the equivalence principle: the ambiguity index within a tolerance, enough propositions in the same class, and no outright contradiction. That is a consensus rule over interpretation, not over bytes.

Model diversity is the signal

Disagreement between parties is the product. Disagreement between validators is the risk, so the contract keeps the LLM on a short leash (stance and evidence strength only) and derives every number that moves money in plain code.

Greybox by construction

Evidence is untrusted. A deterministic scan flags instruction-like text, and a flagged party's evidence weight is capped before anything is derived. An attacker who tries to steer the record loses influence instead of gaining it.

How to read this demo. The validator readings are recorded stand-ins for what independent models return; they are replayed, not fetched live. Everything derived from them (status, divergence, ambiguity, lean, release percentage, the equivalence checks, the injection cap) runs in derive.js, which is parity-tested against contracts/concordance.py on the demo and on 300 random inputs. The contract is deployed on GenLayer Studio, where 4 of 4 convenes reached majority agreement. Real models gave noisier numbers than this scripted replay (ambiguity 60–82, no clean drop after round 2); see docs/EQUIVALENCE.md. Not yet run on Bradbury.
